# CSharpRewriter

Use this skill when configuring the built-in `CSharpRewriter` transformer in a consuming project. For general compression attributes, file inputs, and custom transformer guidance, also consult `../compressedstatics/SKILL.md`.

## Selecting the transformer and options

Select `CSharpRewriter` with the `Transformer` argument on `CompressFile` or `CompressString`. The transformer's options control which rewrites are enabled:

| Option                      | Effect                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `RewritePublicToInternal`   | Changes public top-level types to internal.                                                                         |
| `AddAutoGeneratedHeader`    | Adds an auto-generated source header.                                                                               |
| `AddAutoGeneratedAttribute` | Adds `GeneratedCodeAttribute` using the host assembly name and version.                                             |
| `AddEmbeddedAttribute`      | Adds `Microsoft.CodeAnalysis.EmbeddedAttribute` to top-level types.                                                 |
| `AddNullableDirective`      | Adds `#nullable enable` for nullable property or indexer types and the source has no `#nullable` directive already. |
| `RewriteTypeNames`          | Fully qualifies resolvable type names and removes imports when safe.                                                |
| `RewriteExtensionCalls`     | Rewrites supported extension invocations as static calls.                                                           |
| `AggressiveImportRemoval`   | Allows resolvable imports to be removed despite binding errors; requires `RewriteTypeNames`. Use cautiously.        |

`None`, `Basic`, `Default`, and `All` are predefined option combinations. See `Usage.md` for complete examples and how to pass `TransformerArguments`.

## Assembly-wide configuration

Declare `CSharpRewriterIgnoreAttribute` and `CSharpRewriterTypeMappingAttribute` as assembly attributes in a separate compiled file in the consuming project. 
A convenient filename is `CSharpRewriter.Configuration.cs`. Configuration placed in a referenced assembly or only in the payload is not a substitute for host-project assembly configuration.

```csharp
using Gori.CompressedStatics;

[assembly: CSharpRewriterIgnore("CS0656", "System.Runtime.CompilerServices.RequiredMemberAttribute")]
[assembly: CSharpRewriterTypeMapping("MyLibrary.GeneratedContext")]
[assembly: CSharpRewriterTypeMapping("MyLibrary.Extensions", "Old.Extensions",
    ExtensionMethods = ["SomeExtension(*, string, ...)", "OtherExtension"])]
```

### Ignore rules

- An ignore consists of a compiler diagnostic ID and an optional, case-sensitive message substring.
- An ignore does not suppress the compiler diagnostic. It tells CSharpRewriter that a matching binding error need not block normal import cleanup.
- Polyfill libraries may cause compiler errors that retain imports. The code fix for a recognized polyfill issue can add the full set of required ignore attributes. For other binding issues, a fix can add a rule for that diagnostic and message.

### Type mappings

- A type mapping gives an unresolved source type path a destination type path. If `replaces` is omitted, the final segment of the destination is used as the source name.
- Mappings are used only when semantic resolution fails; they do not override successfully resolved types. The longest matching source path is preferred. Conflicting rules for the same source key are reported.
- Type paths should be fully qualified names without `global::` or generic arguments. Mapping a containing type can preserve generic arguments on nested types.

### Extension mappings

- Extension mappings list methods available on the destination type. `*` matches any parameter type, and a trailing `...` allows additional parameters. A method name without parameter patterns matches any parameters.
- Extension-call rewriting must be enabled. Only supported invocations can be rewritten; conditional access, method groups, and calls that cannot be safely bound may remain unchanged.

## Diagnostics and code fixes

- `GCS034` reports invalid configuration values; `GCS037` reports conflicting rules.
- `GCS035` warns when an ignore has no message filter, because it matches every compiler diagnostic with that ID.
- `GCS036` is an error for an unfinished placeholder destination. Replace it with the intended fully qualified type destination. Placeholder mappings do not take effect until completed.
- `GCS038` warns about a compiler binding error in the transformed source. An ignore may permit import cleanup when that error is understood and intentional.
- `GCS039` warns about an unresolved or ambiguous type or extension reference. A code fix can add a placeholder mapping; replace its placeholder destination with the real destination.
- The available fixes add the complete missing polyfill ignore set, add a specific ignore for another binding diagnostic, or add a placeholder type/extension mapping. They create or update `CSharpRewriter.Configuration.cs` and preserve existing configuration.

Unresolved references and imports needed by the destination context can remain in the output. Review rewritten output in the context where the embedded source will be compiled, especially when using mappings or aggressive import removal. Refer to the package's `Usage.md` for detailed configuration syntax and standalone API examples.
